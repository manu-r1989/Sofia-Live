# Sofia 4.49–4.51.7

This release builds on the existing situation snapshot, Hamburg day rhythm,
weather/photo checks, dialogue continuity and contact limits. It does not replace
those systems or change the voice, WebRTC, half-duplex, lipsync or avatar assets.

## 4.49 — Shared everyday situation

| Step | Delivered behavior |
| --- | --- |
| 4.49.1 | Current situation remains the shared source for status, chat, Live and photos. |
| 4.49.2 | Explicit current location corrections are committed before text/Live responses and photo routing. |
| 4.49.3 | Negated, quoted, past, hypothetical and ambiguous place statements do not become current locations. |
| 4.49.4 | Bed/sofa/learning posture follows the corrected scene; outfit, hairstyle and identity remain intact. |
| 4.49.5 | Corrections retain their bounded validity; night university corrections are rejected. |
| 4.49.6 | Observed transitions and day history record accepted corrections; the reply classifier cannot undo the same turn's correction. |
| 4.49.7 | Integration checks cover pre-response persistence, shared text/Live context and the next photo request. |

The inexpensive prefilter performs no additional model call and no additional
scene read for ordinary conversation. It accepts only a narrow set of explicit
present-tense statements about Sofia. Other corrections continue through the
existing evidence-checked planner. CAS retries protect concurrent scene updates.

## 4.50 — Conversation initiative

| Step | Delivered behavior |
| --- | --- |
| 4.50.1 | A bounded turn-specific impulse chooses response, opinion, reaction, reference or optional question. |
| 4.50.2 | Own views include a concrete reason and can differ politely. |
| 4.50.3 | Reactions and observations can end naturally without another question. |
| 4.50.4 | Recent impulses, existing unanswered questions and initiative settings limit new questions. |
| 4.50.5 | Only relevant open, unexpired, unasked and non-closed threads may be brought back. |
| 4.50.6 | Recent dialogue records the impulse; listening, sensitive turns, brief replies and closing override initiative. |
| 4.50.7 | Regression tests cover variation, quiet settings, topical relevance and closed threads. |

These are generation instructions, not a claim of deterministic wording. The
current request always comes first. No new permanent user facts, real actions,
completed projects or shared events are invented by the impulse selector.

## 4.51 — Proactive messages and controls

| Step | Delivered behavior |
| --- | --- |
| 4.51.1 | Contact status explains off, quiet time, pause, unread messages, activity, spacing or daily budget. |
| 4.51.2 | Existing frequency presets, Hamburg quiet times and temporary daily choices remain available together. |
| 4.51.3 | Existing unread/response pauses remain authoritative; disabling photos during generation prevents photo-contact delivery. |
| 4.51.4 | Unread contacts have bounded text previews and German Hamburg timestamps in the message settings. |
| 4.51.5 | A contact opens its exact chat entry or associated gallery photo. Viewing the list alone does not acknowledge it. |
| 4.51.6 | Changed settings show unsaved/saving/saved feedback; partial quiet-time changes cannot collapse the saved interval. |
| 4.51.7 | PWA assets/cache are versioned 4517v1 and the test banner shows 4.51.7. |

Default natural frequency remains 3–7 contacts/day; photos count toward the
existing budget. No contact is guaranteed and the budget need not be exhausted.
Contact previews are authenticated exactly like the existing social endpoint and
do not contain subscriptions, private push keys or internal model metadata.

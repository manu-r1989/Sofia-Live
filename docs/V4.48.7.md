## Storage and boundaries

The local keys sofia_draft_v448, sofia_ui_v448, sofia_pins_v448 and sofia_read_at_v448 are separate from the assistant's long-term memory and server social settings. They do not synchronize between devices. Pinning never teaches a permanent user fact. Search covers the loaded history only. Drafts are never automatically submitted after reload. The test reset removes local drafts, pins and reading state as well as prior test keys.

No new dependencies, secrets, environment variables, quotas or scheduled jobs. The production access gate remains in place. live.js and the stable avatar/voice pipeline are unchanged. The image provider/model and generation quota are unchanged.

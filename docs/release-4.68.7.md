# Sofia V4.68.7 — photo editing, gallery and role continuity

Release implements the agreed 4.66–4.68 stages as one reviewable change. No voice, WebRTC, half-duplex, lipsync or avatar asset changes. No environment, protection, namespace or budget changes. Asset/cache version: 4687v1.

## 4.66 — reliable photo changes

1. Detect contradictory rear/front-face, camera/body and multiple compass choices before paid classification; ask a specific clarification.
2. Keep an explicitly selected source through a short-lived clarification; expiry prevents unrelated later replies from reusing it.
3. Treat camera, head, gesture, expression and body edits separately; preservation clauses are not edit instructions.
4. Freeze source ID, capture time and compact source snapshot; recheck availability before generation.
5. Never substitute a deleted, expired or unpublished source; unavailable-source UI requires a new selection.
6. Keep past photo discussion from overwriting current role location/outfit; shared context distinguishes capture and current life.
7. Keep clear image mismatches unpublished with safe, honest feedback; existing bounded retry and source/result review remain.

## 4.67 — gallery and Today

1. One compact editor combines camera, light, crop, expression, head and body choices into one explicitly submitted job.
2. Source preview shows the original capture date/time in German format; selected source is frozen at submission.
3. Empty editor, cancellation and navigation start no job; busy state retains the user's choices.
4. Comparison shortcuts show source / 50% / variant with corrected accessible slider semantics and two close controls.
5. Gallery shows matching-photo count and informative empty-filter results; existing date/time grouping and filter restoration remain.
6. Today includes compact section counts and read-only reminder, priority and notes in task detail; exact photo/variant navigation remains.
7. Today coalesces refreshes, disables duplicate refresh gestures and keeps partial results; narrow photo controls wrap with bounded layout.

## 4.68 — current role and initiative

1. Shared Text/Live context names one current station for status, activity, outfit and posture.
2. Observed station transitions do not invent trips or shared events between them.
3. Natural opinions can continue a conversation without another compulsory question.
4. Explicit requests for space suppress voluntary questions and photos while allowing ordinary replies and necessary clarification.
5. Sensitive recent conversations and explicit distance suppress proactive contact.
6. Recheck unread/contact readiness immediately before delivery so generation latency cannot send stale initiative.
7. Preserve existing quiet hours, configured contact frequency, topic variety, hourly photo cap and isolation; no higher limits.
